# 2026-11-11 工作台主线优化

用户在美图主要页面调研后同意实施五项优先改进。本轮以减少来回切换、明确修改对象和保留可复用结果为目标，范围限于创作页。调研依据见 [美图调研](meitu-product-audit-2026-11-10.md)。

## 本轮交付

1. **参考适配可见、可改。** 方案卡展示产品身份实拍，图位摘要展示卖点、空间、陈列和对应参考缩略图。参考可放大，长描述用多行输入；可选择借鉴构图摆放或只借鉴氛围。环境自由配色、环境适配产品只改变环境要求。换参考或改用途后仍需重写，避免把旧文字当作新参考分析；已有手动编辑随重写请求传递。
2. **围绕同一张图调整。** 生成图的“描述修改”、预览中的“修改这张图”和版本对比中的“继续调整这张”进入同一面板。左侧展示原图，右侧写要改与保留的部分；取消后同一页面、同一图片的草稿保留。直接提交现有生图编辑流程，原结果不覆盖。刷新或离开页面不会保存未提交草稿。
3. **同款换色与材质。** 更多操作和放大预览均有入口，可用文字或已上传的图片指定目标，选择保持环境或协调环境配色。新上传但未分类的图片可直接选用，明确记录颜色材质用途，无需先调用 Agent。`appearanceChange` 冻结到生成请求：结构依据原产品实拍，目标颜色材质依据显式要求；后续编辑沿用变体，不恢复旧色。换色和蒙版/扩图分步执行。
4. **无参考策划继续保留。** 对话区提供“参考出场景”和“自主策划”快捷起草，不自动发送。原有规划调用进一步要求说明每张图的表达任务、摆放、机位和光线，没有新增独立模型调用或强制四图模板。
5. **满意图可以手动收藏。** 图片工具栏的“收藏”保存真实图片、生成提示词、参考、方案和一句用途；“我的收藏”可按名称或用途检索、查看旧提示词、带入当前产品。复用只传参考图和用途，旧产品描述保留作追溯，不自动套用。旧“标记优秀”仍是原有 AI 提炼流程。

## 实现边界

- 不改数据库结构。收藏使用现有 `StudioLibraryEntry` 的 `saved_reference` 类型，按账号查询与校验；复用复制私有图片到目标产品资产，沿用原有归属检查。重复保存同一图片更新同一收藏；重复带入同一产品复用同一资产。
- 收藏依赖原生成资产，原图不可用时明确报错，不能把收藏当独立文件备份。
- 换色引用必须属于当前产品且可用；原图、产品实拍、颜色材质图都进入最终输入。模型上限不足以保留颜色图时返回提示，用户自行更换模型；不静默删图或自动换模型。
- 不修改产品档案、旧冻结方案、费用公式、额度、记账、双网关或队列。沿用现有默认数量、分辨率和参数。单图编辑仍需要已确认的产品档案和图包方案。
- 自动搜参考、自动推荐、场景/道具卡归纳、批量变体和全站改版未在本轮实现。
- 样式集中在 `workspace.css`，工作台用 `data-workspace`，新增弹层用 `data-workspace-flow` 限定。

## 验证与试用

技术检查及结果在 [开发记录](CHANGELOG.md) 中记录。单元测试覆盖最终 KIE 请求的图片顺序、颜色约束及连续编辑、上限和越权拒绝；收藏测试使用模拟数据库与存储。浏览器测试使用真实组件，所有 API、图片、模型目录均拦截成本地模拟，外网请求拒绝，截图和 trace 关闭。

建议用一个已有产品按以下顺序试用：

1. 上传实拍和场景参考，在方案卡展开图位，修改陈列或环境配色。更换参考用途后点“按意见重写”，核对描述与参考一致，再采用方案。
2. 选一张生成图，点“描述修改”，输入只移动一件道具。取消再打开应保留草稿；提交后检查新版本，原版本仍在。
3. 从放大预览或更多操作进入“同款换色 / 材质”，选目标色实拍或写颜色。出图后再修改道具，检查是否保留新配色以及原造型和机位。
4. 收藏满意图，写明下次想借鉴的摆放或光线。换另一个产品，从“我的收藏”带入，检查引用用途；确认后续策划没有套用旧产品结构和颜色。
5. 不提供参考，点“自主策划”，核对陈列是否具体、多个图位是否各有表达任务，再决定出图。

本地模拟仅验证请求和交互，没有生成真实图片；不能据此宣称产品一致性、出图可用率或审美已经提高。本轮没有提交、推送或重新部署。
