4. 模型品牌首字母块替换为本地官方 SVG，20px 圆形容器。来源与提取说明见 [sources.json](../../../public/design-preview/brands/sources.json)。Seedream 使用 ByteDance 官方图形；Nano Banana 使用 Google Gemini 官方图形。项目内的虚构品牌另有本地示意 Logo，旧占位字母可兼容迁移，既有任务数据保留。
5. 任务入口仅在对话空状态出现。空画布改成大拖放区和“从模板开始”链接；拖入实拍会保留原图并交给现有建档确认流程。空画布隐藏小地图，操作提示仅首次显示 5 秒，之后通过问号打开。
6. 定稿图包移除每张图片的终稿角标，Frame 标题展示实际终稿数。含文字图位的标签放在图片外侧下方；保留缩放反向补偿。顶栏未建档或理解度 0 时不显示圆环，显示“产品卡 · 未建档”。
7. 生图模型胶囊在首页、工作台常驻；更多菜单只放图片参数等次要项。联网胶囊显示“联网 开 / 关”，关闭呈灰。工具行保持单行，模型文字在窄屏可省略，胶囊入口不隐藏。
8. 三个变体各占约 56px 一行，含 32px 色块、名称、材质、上传面料实拍、删除。可切换“换颜色 / 换材质”；换材质没有逐个上传实拍时禁用生成，并在配方规则层拒绝。图位和费用步骤与三行变体同屏可见；配方区分仅换颜色与仅换材质。首页发起任务沿用首页当前模型选择。
