## 本次实现

- 空对话 5 张入口卡，点击后在当前对话确认任务；空画布提供上传、图包、批量换色和模板 4 个入口。
- 批量换色选择已有终稿或样例图包，每个变体可以编辑名称、材质、色卡颜色，上传面料实拍或删除；选择套用图位。超过 $0.20 先确认。生成 `SF-2401-米白 / 雾灰 / 焦糖` 三组 Frame，产品卡同步显示变体。
- 每张任务记录冻结源图、全部原始实拍、变体参考、当前模型和品牌快照。缺少参考、无效图位、重复变体名都会阻止生成。场景、机位、构图、道具及原文保留约束写入配方。
- 多语言仅选择有文字的图位；US/UK/DE/FR/JP 映射语言，按术语表取固定译法。超出原文区域容量时显示确认卡，确认后保留原字号和排版继续；输出按站点命名 Frame。术语表可在模板库第六个 Tab 新建、编辑、搜索和保存。
- 导出入口自动打开一张样例检查卡，展示每张图通过或需要注意、缩略图及问题区域示意；覆盖 IP 内容类别和平台参数，允许“仍然导出”。
- SKU 旁品牌胶囊支持选择、清除、搜索；后台品牌管理支持新增、名称、Logo 上传、主色、光线、风格、色调、默认场景、禁用元素的修改。适用品类下优先选择品牌默认场景，`PromptComposer` 将品牌偏好及禁用项写入实际本地规划结果。
- 输入框联网开关默认开，分辨率自适应 / 1K / 2K / 4K；选择按首页或会话持久化。三段图标主题按钮支持系统、亮、暗。
- 颜色 Frame 和翻译 Frame 刷新后恢复。新任务不会被旧批量画布覆盖；新任务清除旧任务面板，继续原有品类确认及快速/严格逻辑。

## 样例的边界

换色使用 CSS 区域叠色展示组图关系；翻译使用固定术语映射与文本覆盖层展示排版。它们是静态交互示意，不代表生图或翻译质量。导出下载样例源图片，尚未把颜色、译文覆盖层烘焙成最终文件。

检查使用样例元数据和预置 IP 提醒，问题框是示意区域；不会把此结果当成真实内容鉴定，也没有自动质检、自动修复循环。联网开关只保存设置。所有费用为假报价，没有扣费或业务 API 请求。
