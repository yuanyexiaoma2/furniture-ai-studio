# UI 与交互巡检（2026-10-27）

范围：首页上传与模型选项、SKU 首次进入、画布工具、大图入口、编辑取消、下载、账号菜单，以及 390px 手机布局和暗色主题。沿用现有界面，不调用付费模型。

## 已修复

- 首次打开 SKU 时，画布和对话并发创建同一个会话可能返回 500；唯一键冲突后读取已创建会话，不覆盖内容。
- 头像菜单显示真实姓名与角色，设计师隐藏管理员入口，新增退出登录；退出前保存当前布局。
- 手机工作台增加“对话 / 画布”切换，保留未发送文字；恢复顶部账号、设置和导出入口，修复模板库分类撑宽页面。
- 手机扩图弹窗按容器缩放，关闭按钮、取消和确认保持可见；局部重绘工具换行、画布缩放按可用空间适配。
- 首页和对话输入框隐藏没有连接回调的比例、张数控件；Shift+Tab 不再误触发补全。Auto 文案明确当前优先默认模型。
- 同名附件按所点的那一份删除，防止缩略图与真正上传文件不一致。
- 原始实拍只提供引用与下载，避免误点“设为终稿”和生成结果编辑工具；空占位不显示图片工具。浮动工具栏限制在画布范围内，缩小画布时减少按钮与标题重叠。
- 真实编辑取消费用确认后保留笔迹或扩图范围，不提示提交成功；提交期间禁用重复提交。真实工作台不再弹出原型的假效果预览。
- 局部重绘蒙版从缩略图笔迹换算回原图像素，提示词明确第二张参考图是蒙版；2048×1536 原图导出同尺寸蒙版。
- 下载实拍使用服务端文件名和实际扩展名，PNG 不再保存为 WEBP 名称。
- 切换 SKU 清理临时编辑与选择状态，成功加载后清除旧错误提示。

2. **模板库“用这个场景”到真实任务**：库仍含本地原型数据，选择场景尚未完整传入服务端真实策划和生图链路。需要统一模板来源、权限与任务参数，不能把当前点击成功当作模板已应用于生成。
3. **只读成员工具可见性**：服务端继续拒绝越权写入，部分前端操作入口还可进一步按角色收起；本次账号菜单验收使用设计师账号。
4. **依赖维护**：当前 Next.js 仍为 16.4.0，先前页面安全升级提示尚待专门升级与兼容验证，本次没有隐藏提示或执行其建议的命令。

## 如何运行

本次无需新增迁移或模型登记。沿用已有 PostgreSQL、MinIO、`.env`、网页与 worker；网页入口为 `http://localhost:3000/design-preview`。本机服务已运行，刷新页面即可体验。新启动时使用 `npm run dev -- --hostname 127.0.0.1 --port 3000` 和独立的 `npm run worker`，不要重复启动现有服务。
