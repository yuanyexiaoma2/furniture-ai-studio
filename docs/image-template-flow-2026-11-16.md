# 图片模板沉淀与复用 · 2026-11-16

## 使用流程

1. 在创作画布选中满意的生成图，点击“收藏”。弹层读取该图真实生成提示词，填写模板名称、适用品类、场景标签、参考用途，按需要调整可复用提示词后“保存到模板库”。不要求先设终稿，不调用模型。
2. 顶部模板库默认展示“图片模板”，工作台对话区也有“模板库”。可按品类、场景筛选，搜索名称、用途或提示词；工作台优先同品类，未分类的历史收藏仍可用。
3. “查看与编辑”可独立修改模板；原始生成提示词可展开追溯。已有生成任务及图片不受修改影响。
4. “使用模板”在独立模板库先选择已有产品，再进入该产品工作台；在工作台直接选用。可选两种方式：
   - 修改提示词直接生成：带入可编辑提示词，默认选中当前产品前3张实拍及模板图。检查旧产品描述，可取消模板图直传或调整用途、图片、模型、比例与分辨率；点击生成直接走原报价/指纹/额度/队列，无Agent和费用确认。
   - 交给搭档适配：把模板图和待适配提示词带入当前对话，继续说明要用于哪个场景。模板默认只用于Agent看图反推，不直接传给生图模型，产品身份来自当前实拍。
5. 模板生成结果进入独立单张图位，后续仍可继续修改、设终稿、收藏。连续修改保留该生成任务所用实拍与场景参考；换色沿用原换色规则。

没有产品实拍时，模板直接生成入口提示先补充产品资料；独立的普通“单张生图”仍支持零参考纯文字生成。

## 数据与接口

- StudioLibraryEntry沿用saved_reference类型。category、scene、reusablePrompt为可选字段，旧记录无需迁移。prompt保留实际生成快照，reusablePrompt用于模板编辑及本次复用；所有模板查询与编辑按ownerId隔离。
- GET /api/studio/saved-references列出模板；带productId和assetId时只读取生成图的保存草稿。
- POST支持save、update、reuse和prepare。prepare只按确定性标识复制参考到当前产品，无对话写入；reuse保留旧默认行为，withPrompt=true时携带待适配提示词，参考mode=prompt_only。
- 单张接口扩展可选productAssetIds、referencePurpose，服务端检查当前产品归属及photo类型。参考顺序先实拍再模板；用途、图片和描述均进入任务输入及指纹，超模型上限明确拒绝，无静默省略。
- 本次提示词修改不会自动保存回模板；需要长期保留的变化在“查看与编辑”中保存。手动模板与原“标记优秀”的AI提炼确认流程仍各自保留。

## UI

复用现有p-panel、p-subtle、border、muted等主题变量和Bookmark、Search、ImagePlus、MessageCircle图标。模板页与工作台共用图片卡片；图片完整展示、轻边框、紧凑标签。编辑弹层桌面图文双栏，手机单栏；仅新增模板范围样式至workspace.css。没有更换全站字体、主题或首页/后台布局。

## 验证边界

本轮没有真实模型调用、截图或对用户现有图片执行写入。浏览器使用真实组件和模拟API，检查保存、编辑、筛选、目标产品跳转、直接生成/适配分支、取消传图、取消提交、只读权限，以及亮暗主题1440px/390px边界。数据库测试仅创建并清理隔离数据，检查原提示词保留、账号隔离、引用复制、任务输入顺序、指纹变化及零LLM调用。实际出图效果与视觉满意度由用户使用确认。

验收结果：lint、typecheck、216项单元、4项本地集成、build与14项隔离浏览器回归通过。浏览器测试已消除关闭按钮和移动端主题入口的定位歧义；没有以模拟通过宣称实际出图效果。
