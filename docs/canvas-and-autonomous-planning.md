# 无参考策划与画布优化 · 2026-11-09

## 调研依据与边界

实际进入美图设计室官网的“创建 → AI画布”。空白画布提供“对话Agent，从0开始创作”和“上传图片，已有图片进行编辑”两个入口；基础工具包含移动、绘制、图片生成，输入区用 @ 引用上传素材。11月9日仅完成入口观察，不能当作完整产品体验。11月10日补查发现，读取结果中的验证码组件位于屏幕外，并非实际阻挡交互的弹窗；此前关于验证码阻碍的判断不充分，予以更正。

### 2026-11-10 登录后实际交互补查

通过用户登录的 Chrome 查看空白画布及已有家具案例。只打开界面、选择图片和取消编辑，没有上传文件、发送消息、提交生成、保存参考或删除资料；未制作截图。已关闭本次调研创建的标签，保留用户原有标签。

- **同一画布保留两种工作方式**：对话输入区可切换 Agent / 图片生成 / 视频生成。图片生成模式提供图片输入、文字、模型、分辨率、比例、数量和每张费用；画布工具栏也可打开节点附近的生成输入区。仅观察当前控件，不把界面列出的模型等同于已验证能力。
- **选图后显示相关工具**：在已有家具案例选中生成图片，出现 AI改图、抠图、AI超清，以及尺寸调整、消除、扩图等入口。AI改图打开绑定当前图片的修改输入框和取消/改图按钮。本轮取消退出，未提交，因此不评价模型结果或像素保留能力。
- **预览与画布不是同一个操作入口**：点击聊天中的结果打开大图预览，有缩略图切换和下载；在画布选中节点才出现编辑工具。对本项目的启示是让预览也能方便回到该图片继续调整，避免用户找入口。
- **参考保存包含用途**：保存创作参考窗口有名称、用途 Prompt 和待保存图片选择。仅打开并关闭，未保存。用途提示词与图片一起复用值得借鉴，但不能据此认定保存后台一定不调用模型。
- **已观察到的限制**：已有家具案例中，画布及历史消息均有图片，但聊天 @ 菜单显示“你还没有上传内容”。这是该旧任务当时的界面表现，不能泛化为美图所有任务都如此。我们的实现应验证选中、固定引用、历史图片之间确实互通。
- **基础画布操作**：图片右键菜单提供显示全部、复制、创建副本、成组/解组、图层排序和锁定等；没有实际执行复制、删除或改变图层。AI改图进出后缩放发生变化，退出前恢复该案例原来的14%。

对本项目的判断：优先缩短“选图 → 指明怎么改 → 看新结果 → 继续改”的路径；保留用户已写好提示词时的直接生成能力，并明确它是否会被 Agent 重写。无需为了模仿通用设计工具而增加分层、视频或复杂图层体系。本次只补充调研证据，未新增上述产品功能。

以下是本项目的设计判断，不是声称这些产品都按同样方式实现。

## 本轮实现

1. 无参考图位在已有策划调用内完成具体布景：一个视觉重点、合理使用情境、道具位置与疏密、观察面和高度、光线与主体对比。产品事实仍由实拍约束。默认完整推荐方案，不因图位序号强制选择多个方向；已有多方向方案仍须选择，不改旧冻结结果。
2. 明确选中对象；选中图片仍随当次消息发送，已固定引用继续保留。输入区标明“选中 / 引用”，取消选择不清除用户主动固定的引用。移除对象同步清理失效选中、引用和编辑器。
3. “描述修改”选定原图并聚焦输入框，用户自己的文字不会被替换，也不会自动提交。局部重绘、终稿、下载留在常用工具，其他操作归到“更多”，功能保留。
4. 修改前后对比使用完整图片显示，不裁切局部；可选一张继续调整。历史改为按图位找图片版本，工具执行记录留在折叠项。
5. 新图位默认最多三列，用户已有布局保留。“整理画布”是主动布局操作，可以撤销。图位与资料面板可定位各图；隐藏只影响布局，支持恢复，不删资源或终稿。

## 验收走法

### 2026-11-10 视觉与交互补充

用户授权学习美图的交互、UI和图标后，工作台增加独立视觉层：较窄且可收起的对话栏、上下两行的输入区工具、分组的图片操作、版本缩略图、轻边框画布及更明确的主操作。该轮没有增加直接生图模式、免费收藏或其它新业务流程；费用、图像参数及模型请求语义不变。

试用时重点查看：

- 对话区是否够读方案，画布是否比原来更容易看图；输入未发送文字后收起并展开对话，文字及引用是否保留。
- 单选生成图时能否迅速找到描述修改、局部重绘、终稿与对比；引用和收藏是否容易分清。
- 打开图片版本后，能否通过缩略图找到要继续调整的结果；不同宽度、暗色模式下是否有遮挡或拥挤。

本轮技术检查及隔离浏览器操作通过（含1440/1100/820/390px），没有制作截图或运行真实生图。几何边界与可点击检查不代表已完成用户审美验收。

- 产品图与参考资料混合上传：核对标注，选中后描述用途或修改要求；取消选择后观察当前消息不再带旧选图。已固定引用需单独取消。
- 双击看原图 → 描述修改 → 圈改 → 修改前后对比 → 定稿；修改生成用本地模拟验证提交链路，本轮不做实际模型生成。
- 多版本整理、撤销、隐藏、刷新、找回；确认只影响布局，保留原图和已选终稿。
- 无参考输入真实产品与粗略卖点：人工检查策划是否具体、摆放是否合理、改写是否只改指定部分；实际出图满意度待用户试用，技术测试不能代替。
