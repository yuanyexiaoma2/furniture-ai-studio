## 评分与轮次

1. 打开 [已有鞋架评审页](review/NEW-MVQFFV1P.html)，点击“打开可保存评分的评审页”并登录。也可直接打开 /reviews/产品ID。
2. 点击“开始第1轮评分”，冻结当前方案、样图引用及经验库条目数量。每图位选择“采用 / 小改 / 重做”，填写一句原因并保存。
3. 下一轮评审时点击“开始第2轮评分”。旧轮次的方案、样图和库数量保留；不会因规划按钮、确认方案、网页刷新或出图完成而自动增加轮次。
4. [本地汇总](review/summary.html)按产品、轮次显示三档数量、未评数、方案版本、库条目数、评分人和最近评分时间，并对比第一/第二轮。缺第二轮显示等待，不把缺失当作0。
5. 实时汇总为 /reviews/summary。文件方式打开HTML可离线查看；保存评分使用同源、已登录的网页，避免file://跨域与浏览器本地存储分散导致丢记录。保存后自动更新本地HTML。

评分人来自登录账号，时间由服务器记录，页面显示北京时间。方案版本是方案、样图ID和库条目数快照的SHA-256前16位；库同时记录总条目和排除样例/待审/缺图后的可检索条目数。修改评分追加历史记录，统计只使用每图位最后一次评分；重复提交相同评分不重复写历史。
