# 任务13-1：修复卡点并取消费用确认

## 完成内容

- 新版 RealCard的问题卡逐题显示全部问题，有选项可点选，允许自由填写的题有卡内输入框，全部答完后一次提交；答案数量、选项、长度仍由服务端校验。
- 新版 ProfileForm显示原冲突来源，并增加“我已核实，以上填写值为准”；核实后保留当前填写值和资料来源，再保存正式档案，未核实的冲突仍不能保存。
- 新版逐张模式点击生成先出现“当前是逐张模式”和“切回整套 / 只生成当前图位”，不会先报整批错误；只有显式选择整套才切模式，当前图位取已确认方案中第一个待生成图位，保留已保存的候选数量。
- 所有生图/改图入口直接提交，包括Agent工具、旧页批量生成、失败重试、画布换背景/抠图/再来一张、局部重绘/消除/扩图，以及后台网关连通性测试。局部/扩图保留编辑器提交选区的确认，之后不再弹费用确认；旧费用卡退出等待，旧自动确认金额阈值不再拦截提交。
- 原产品理解、方案冻结、终稿选择和数据覆盖/删除确认保留；这些不是费用确认。没有新增功能开关或关闭联网、竞品、模板库等功能。

## 费用和样式边界

服务端仍估价、检查额度、预留、写任务并记账，直接提交仍复用原有事务、指纹和队列。报价与提交间指纹变化时自动刷新一次，仍用同一提交编号；断网重试复用编号，提交成功后只是刷新失败不提示成“生成失败”。余额不足原样报错、不创建新任务。

按钮附近显示预估小字，画布图片信息显示任务费用；只有真实账单回填且不是估值时标“实际”，其他情况标“预估/待回填”，不把估值冒充实际。旧商品页/图包页已有的任务费用信息保留。

本轮没有修改CSS、颜色、字体、圆角、间距或按钮样式定义。新增控件和费用文字沿用现有组件与类名，图片工具条共用一条单次估价，避免给每个按钮重复加文字而撑宽工具条。

## 手动体验步骤

1. **多问题卡**：在新版工作台让Agent一次提2～3题；逐题选项或填写，全部填完后“提交回答”可点，提交一次应保存全部答案，不再报数量不符。
2. **档案冲突**：打开有尺寸等冲突的档案卡，改成你确认的值，再勾该字段的“我已核实，以上填写值为准”；保存后应建立正式档案，未核实的其他冲突仍须先核实。
3. **逐张模式**：在旧Agent页切到“手动·逐张”，返回同产品新版工作台点“生成候选”；应出现两种选择，“只生成当前图位”推进首个未定稿图位，“切回整套”才切模式并提交整套。
4. **直接生图/改图**：确认方案后点生成，或选图点换背景、抠图、再来一张，应直接排队，没有费用卡/浏览器费用弹窗；小字显示估价，完成后选中图片看费用信息。
5. **局部/扩图**：画好蒙版或调整扩图范围，填写要求后点编辑器里的确认；应直接提交，不再出现第二次费用确认，原图保留。
6. **旧页和额度**：旧图包页点批量或失败重试也直接提交；使用已无可用额度的账号会收到配额不足提示，不能绕过预留和记账。

本任务不推送。13-0的docs/current-flow.md保持原样且不纳入本次提交，作为修改前流程记录。
