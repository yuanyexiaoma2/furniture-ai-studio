# 第三方代码与设计参考

## Loomic

来源：https://github.com/fancyboi999/Loomic

参考版本：21206c30054572291b9df000d84568aeca97aeda。

本项目的画布摘要、选图引用、工具进度展示和自动保存流程参考并适配了 Loomic 的相关实现，使用现有 React Flow、Prisma、Auth.js 及任务队列重新接入。不包含 Loomic 的品牌图片、字体资产、支付或模型服务配置。
